# The role of DNA methylation in predicting the expression of pharmacogenes

Pharmacogenetics (PGx) research has significantly improved our understanding of interindividual variance in drug response. Emerging data show that epigenetic modifications, such as DNA methylation (DNAm) markers, can explain additional variance. DNAm sites are stable yet modifiable markers of lifelong environmental exposures, making them an interesting biomarker for drug response. However, current drug response models rely on genetic information to predict phenotypes. We quantify how much genetic and epigenetic features from blood samples explain variance in the gene expression of 411 known pharmacogenes (including CYP2D6, CYP3A5, DPYD, F5, HLA-B, TPMT, and VKORC1). We find that while genetic information alone (R2 = 0.405) outperforms DNAm models (R2 = 0.331) on average, some gene classes, such as HLA genes, are best modeled using DNAm data. Moreover, models that combine both modalities of data significantly outperform (R2 = 0.438) models using either modality alone. In these combined models, 33.3% of the information used in prediction comes from DNAm. Further, in a variance decomposition analysis, we find that an average of 77.4% of the variance explained in genetic models is captured via DNAm, thus making it an impactful biomarker. This work demonstrates that DNAm can explain variance in pharmacogene mRNA levels in blood and reflects the genetically driven expression of these genes.

This Github contains summarized feature-level model weights along with output metrics per gene. Scripts used in the analysis are also provided.
